# 🌎🛰️ EpidemIA
## Sobre o Projeto

O EpidemIA é uma plataforma preditiva que utiliza Inteligência Artificial e dados satelitais para prever regiões com potencial risco de surtos de doenças transmitidas por vetores.

A solução foi desenvolvida para a Global Solution FIAP 2026 dentro do tema Economia Espacial.

## Problema

Atualmente o combate a doenças como dengue, zika e malária é majoritariamente reativo.

As ações preventivas geralmente acontecem após o aumento dos casos, causando sobrecarga dos serviços de saúde e maiores impactos sociais.

## Solução

O EpidemIA utiliza:

- Dados climáticos obtidos por satélites
- Inteligência Artificial
- Histórico epidemiológico
- Mapas de calor
- Alertas preditivos

para identificar regiões com maior probabilidade de surtos antes que eles ocorram.

## Funcionalidades

- Dashboard de monitoramento
- Índice de Risco Epidêmico (IRE)
- Mapa de calor de regiões críticas
- Alertas preditivos
- Aplicativo para agentes de saúde
- Gestão preventiva de surtos
